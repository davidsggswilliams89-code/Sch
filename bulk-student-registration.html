BULK STUDENT REGISTRATION

Register many students at once using the same Student record structure used by create-access.html. Firebase Authentication creates the login, while Firestore stores the student school record and linked user record.

01 PreparePaste pipe, CSV or TSV rows.
02 PreviewCheck Programme and Level.
03 CreateCreate Auth + student + user.
04 ExportDownload successful credentials.
Fields — exactly matched to Create AccessFull Name, Student ID / Matric No., Admission Number, Programme, Academic Level, Account Status, login Email and Password. Programme is taken from the selected programmes document name field, exactly like Create Access. Academic Level is taken from the selected academicLevels document.
Header row is optional. Column order is fixed: Full Name | Student ID | Admission Number | Email | Password | Programme | Level | Status. Status may be omitted and will use the Default Account Status. Programme and Level must match the values loaded from Create Access.
