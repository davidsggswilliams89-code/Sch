1. Create User

Create a school user account and store the Firebase Authentication UID in the SMS users collection.

User Account

The created Authentication UID is automatically saved as uid, authUid and firebaseUid so existing pages can match the account using their current UID lookup patterns.

UID Matching

The page uses the signed-in Firebase UID to identify the current Registrar. Existing SMS records are matched using uid, authUid or firebaseUid. User records created here receive all three UID fields.
